= 管理 StorageGRID 存储桶策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以控制 S3 存储桶和该存储桶中对象的用户访问权限。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到租户管理器。
* 您属于具有 link:tenant-management-permissions.html["root 访问权限"] 的用户组。"查看所有存储桶"和"管理所有存储桶"权限仅允许查看。
* 您已验证所需数量的存储节点和站点可用。如果任何站点中有两个或多个存储节点不可用，或者站点不可用，则对这些设置的更改可能不可用。


.步骤
. 选择*存储桶*，然后选择要管理的存储桶。
. 在存储桶详细信息页面上，选择*存储桶访问权限* > *存储桶策略*。
. 执行以下操作之一：
+
** 通过选中*启用策略*复选框输入存储桶策略。然后输入有效的 JSON 格式字符串。
+
每个存储桶策略的大小限制为 20,480 个字节。

** 通过编辑字符串来修改现有策略。
** 通过取消选择*启用策略*来禁用策略。




有关存储桶策略的详细信息，包括语言语法和示例，请参见 link:../s3/example-bucket-policies.html["存储桶策略示例"]。
