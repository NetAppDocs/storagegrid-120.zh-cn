= 在 StorageGRID 中删除您自己的 S3 访问密钥
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果使用的是 S3 租户，并且拥有相应的权限，则可以删除自己的 S3 访问密钥。删除访问密钥后，它不能再用于访问租户帐户中的对象和存储桶。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到租户管理器。
* 您有 link:tenant-management-permissions.html["管理自己的 S3 凭据权限"]。



CAUTION: 可以使用租户管理器中为您的帐户显示的访问密钥 ID 和密钥访问属于您的帐户的 S3 存储桶和对象。为此，请像保护密码一样保护访问密钥。定期轮换访问密钥，从您的帐户中删除任何未使用的密钥，并切勿与其他用户共享这些密钥。

.步骤
. 选择 *STORAGE (S3)* > *My access keys*。
. 在"我的访问密钥"页面中，选中要删除的每个访问密钥的复选框。
. 选择*Delete key*。
. 在确认对话框中，选择*Delete key*。
+
页面右上角会显示一条确认消息。
