= 更改 StorageGRID 中 S3 存储桶的对象版本控制
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果使用的是 S3 租户，则可以更改 S3 存储区的版本控制状态。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到租户管理器。
* 您属于具有 link:tenant-management-permissions.html["管理所有存储桶或根访问权限"] 的用户组。这些权限将覆盖组或存储桶策略中的权限设置。
* 您已验证所需数量的存储节点和站点可用。如果任何站点中有两个或多个存储节点不可用，或者站点不可用，则对这些设置的更改可能不可用。


.关于此任务
您可以启用或暂停存储桶的对象版本控制。为存储桶启用版本控制后，它无法返回到未版本控制的状态。但是，您可以暂停存储桶的版本控制。

* 已禁用：从未启用过版本控制
* Enabled：已启用版本控制
* 已挂起：版本控制之前已启用，现已挂起


有关详细信息，请参见以下内容：

* link:../s3/object-versioning.html["对象版本控制"]
* link:../ilm/example-4-ilm-rules-and-policy-for-s3-versioned-objects.html["S3 版本化对象的 ILM 规则和策略（示例 4）"]
* link:../ilm/how-objects-are-deleted.html["如何删除对象"]


.步骤
. 从控制面板中选择*查看存储桶*，或选择*存储（S3）* > *存储桶*。
. 从表中选择存储桶名称。
+
此时将显示存储区详细信息页面。

. 在*存储桶选项*选项卡中，选择*对象版本控制*折叠面板。
. 为此存储桶中的对象选择版本控制状态。
+
对于用于跨网格复制的存储桶，必须保持启用对象版本控制。如果启用了 S3 Object Lock 或旧版合规性，则*对象版本控制*选项将被禁用。

+
[cols="1a,3a"]
|===
| 选项 | 问题描述 


 a| 
启用版本控制
 a| 
如果要在此存储桶中存储每个对象的每个版本，请启用对象版本控制。然后，您可以根据需要检索对象的早期版本。

已在存储桶中的对象在被用户修改时将进行版本控制。



 a| 
暂停版本控制
 a| 
如果不想再创建新对象版本，请暂停对象版本控制。您仍然可以检索任何现有对象版本。

|===
. 选择 *Save changes*。
