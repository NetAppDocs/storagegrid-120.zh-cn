= Sign out StorageGRID 租户管理器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用租户管理器后，必须注销以确保未经授权的用户无法访问 StorageGRID 系统。根据浏览器 Cookie 设置，关闭浏览器可能不会使您退出系统。

.步骤
. 在用户界面的右上角找到用户名下拉菜单。
+
image:tenant_user_sign_out.png["注销链接"]

. 选择用户名，然后选择*Sign out*。
+
** 如果未使用 SSO：
+
您已退出管理节点。此时将显示租户管理器登录页面。

+

NOTE: 如果您登录到多个管理节点，则必须注销每个节点。

** 如果启用了 SSO：
+
您已注销您正在访问的所有管理节点。此时将显示 StorageGRID 登录页面。您刚刚访问的租户帐户名称在*最近帐户*下拉列表中显示为默认名称，并显示租户的*帐户 ID*。

+

NOTE: 如果已启用 SSO，并且您也已登录到 Grid Manager，则还必须注销 Grid Manager 才能注销 SSO。
