= 在 StorageGRID 中查看 S3 存储桶详细信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看租户帐户中的存储桶。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到租户管理器。
* 您属于具有 link:tenant-management-permissions.html["Root 访问权限、管理所有存储桶或查看所有存储桶权限"] 的用户组。这些权限将覆盖组或存储桶策略中的权限设置。


.步骤
. 从控制面板中选择*查看存储桶*，或选择*存储（S3）* > *存储桶*。
+
此时将显示 Buckets 页面。

. 查看每个存储桶的汇总表。
+
根据需要，您可以按任何列对信息进行排序，也可以在列表中前后翻页。

+

NOTE: 显示的对象计数、使用的空间和使用量值是估计值。这些估计值受摄取时间、网络连接和节点状态的影响。如果存储区已启用版本控制，则删除的对象版本将包含在对象计数中。

+
名称:: 存储区的唯一名称，无法更改。
已启用的功能:: 已为存储区启用的功能列表。
S3 对象锁定:: 是否已为存储桶启用 S3 Object Lock。
+
--
仅当为网格启用了 S3 Object Lock 时，才会显示此列。此列还显示任何旧版兼容存储桶的信息。

--
地区:: 存储桶所在的区域，无法更改。默认情况下，此列处于隐藏状态。
对象计数:: 此存储桶中的对象数。如果存储桶已启用版本控制，则此值中包括非当前对象版本。
+
--
添加或删除对象时，此值可能不会立即更新。

--
已用空间:: 存储桶中所有对象的逻辑大小。逻辑大小不包括复制或擦除编码副本或对象元数据所需的实际空间。
+
--
此值可能需要长达 10 分钟才能更新。

--
用途:: 存储桶的容量限制所使用的百分比（如果已设置）。
+
--
使用值基于内部估算，在某些情况下可能会超出。例如，当租户开始上传对象时，StorageGRID 会检查容量限制（如果已设置），如果租户已超出容量限制，则拒绝向此存储桶新接收数据。但是，在确定是否超过容量限制时，StorageGRID 不会考虑当前上传的大小。如果删除对象，在重新计算容量限制使用量之前，可能会暂时阻止租户将新对象上传到此存储桶。计算可能需要 10 分钟或更长时间。

此值表示逻辑大小，而不是存储对象及其元数据所需的物理大小。

--
容量:: 如果设置，则为存储桶的容量限制。
创建日期:: 创建存储桶的日期和时间。默认情况下，此列处于隐藏状态。


. 要查看特定存储桶的详细信息，请从表中选择存储桶名称。
+
.. 查看网页顶端的摘要信息，以确认存储区的详细信息，例如区域和对象计数。
.. 查看容量限制使用情况和对象计数限制使用情况栏。如果使用率为 100% 或接近 100%，请考虑增加限制或删除某些对象。
.. 根据需要，选择*删除存储桶中的对象*和*删除存储桶*。
+
[CAUTION]
====
请密切关注选择这些选项时出现的注意事项。有关详细信息，请参阅：

====
