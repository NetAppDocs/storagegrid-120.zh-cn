= 了解 StorageGRID 分支存储桶
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
分支存储桶提供对存储桶中在特定时间存在的对象的访问。

您可以从现有存储桶创建分支存储桶。创建分支存储桶后，从中创建的原始存储桶称为 _base bucket_。此外，您可以从另一个分支存储桶创建分支存储桶。

分支存储桶提供对受保护数据的访问，但不用作备份。要继续保护数据，请在基本存储桶上使用以下功能：

* link:../tenant/using-s3-object-lock.html["S3 对象锁定"]
* link:../admin/grid-federation-what-is-cross-grid-replication.html["跨网格复制"] 用于基础存储桶
* link:../tenant/manage-bucket-policy.html["存储区策略"] 用于版本化存储桶以清理旧对象版本


请注意分支桶的以下特性：

* 您可以使用 link:../tenant/use-s3-console.html["S3 Console 下载对象"] 访问分支桶中的对象。
* 当客户端访问分支存储桶中的对象时，分支存储桶的 link:../s3/use-access-policies.html["访问策略"]（而不是基本存储桶的策略）决定是授予还是拒绝访问。
* 在基本存储桶中创建的对象将根据 ILM 规则如何link:../ilm/access-create-ilm-rule-wizard.html["ILM规则"]应用于基本存储桶进行评估。在分支存储桶中创建的对象将根据 ILM 规则如何应用于分支存储桶进行评估。
* 分支存储区不支持跨网格复制。
* 分支存储桶不支持平台服务。




[[examples-for-branch-bucket-usage]]
== 分支桶使用示例

* 您可以使用分支存储桶来删除损坏的对象，方法是从损坏发生之前的某个时间点创建分支存储桶，然后将应用程序指向分支存储桶，而不是指向包含损坏对象的基本存储桶。
* 您正在将数据保存在版本化存储桶中。发生了一个意外漏洞，导致许多不需要的对象在时间 _T_ 后被摄入。您可以为 Before 时间值 _T_ 创建分支存储桶，并将客户端操作重定向到该分支存储桶。然后，只有在 Before 时间 _T_ 之前摄取的对象才会暴露给客户端。




[[operations-on-objects-in-branch-buckets]]
== 对分支存储桶中对象的操作

* 分支存储桶上的 PUT 对象操作在分支中创建对象。
* 分支存储桶上的 GET 对象操作从分支检索对象。如果对象不存在于分支存储桶中，则从基本存储桶中检索对象。
* 从分支存储桶中删除对象的过程如下：
+
[cols="1a,1a,2a,2a,2a"]
|===
| 操作 | 目标 | 结果 | 基本桶中的对象可见性 | 分支桶中的对象可见性 


 a| 
删除没有版本 ID
 a| 
基本存储桶
 a| 
仅为基本存储桶创建删除标记
 a| 
HEAD/GET 返回对象不存在，但仍可访问特定版本
 a| 
HEAD/GET 返回 Object 存在，并且仍可访问特定版本

删除标记将在分支存储桶的 `beforeTime`之后创建。



 a| 
使用版本 ID 删除
 a| 
基本存储桶
 a| 
已删除基本存储桶和分支存储桶的特定对象版本
 a| 
HEAD/GET 返回对象版本不存在
 a| 
HEAD/GET 返回对象版本不存在



 a| 
删除没有版本 ID
 a| 
分支存储桶
 a| 
仅为分支存储桶创建删除标记
 a| 
HEAD/GET 返回对象（基本桶对象不受影响）
 a| 
HEAD/GET 返回对象不存在



 a| 
使用版本 ID 删除
 a| 
分支存储桶
 a| 
仅针对分支存储桶删除特定对象版本
 a| 
HEAD/GET 返回特定对象版本（基本存储桶对象不受影响）
 a| 
HEAD/GET 返回对象版本不存在

|===
