= 在 StorageGRID 中启用或禁用上次访问时间更新
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当网格管理员为 StorageGRID 系统创建信息生命周期管理 (ILM) 规则时，他们可以选择指定使用对象的最后一次访问时间来确定是否将该对象移动到不同的存储位置。如果使用的是 S3 租户，则可以通过启用 S3 存储桶中对象的上次访问时间更新来利用此类规则。

这些说明仅适用于包含至少一个将*上次访问时间*选项用作高级过滤器或参考时间的 ILM 规则的 StorageGRID 系统。如果您的 StorageGRID 系统不包含此类规则，您可以忽略这些说明。有关详细信息，请参阅 link:../ilm/using-last-access-time-in-ilm-rules.html["使用 ILM 规则中的上次访问时间"]。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到租户管理器。
* 您属于具有 link:tenant-management-permissions.html["管理所有存储桶或根访问权限"] 的用户组。这些权限将覆盖组或存储桶策略中的权限设置。


.关于此任务
*最后访问时间*是 ILM 规则的*参考时间*放置说明的可用选项之一。将规则的参考时间设置为最后访问时间后，网格管理员可以根据上次检索（读取或查看）对象的时间，指定将对象放置在特定存储位置。

例如，为了确保最近查看的对象保留在更快的存储上，网格管理员可以创建一个指定以下内容的 ILM 规则：

* 过去一个月内检索的对象应保留在本地存储节点上。
* 在过去一个月中未检索到的对象应移动到异地位置。


默认情况下，上次访问时间的更新处于禁用状态。如果您的 StorageGRID 系统包含使用*上次访问时间*选项的 ILM 规则，并且您希望此选项应用于此存储桶中的对象，则必须为该规则中指定的 S3 存储桶启用上次访问时间的更新。


CAUTION: 更新检索对象时的上次访问时间可能会降低 StorageGRID 性能，尤其是对于小型对象。

上次访问时间更新会影响性能，因为每次检索对象时，StorageGRID 都必须执行以下额外步骤：

* 使用新时间戳更新对象
* 将对象添加到 ILM 队列中，以便根据当前 ILM 规则和策略重新评估它们

.步骤
. 从控制面板中选择*查看存储桶*，或选择*存储（S3）* > *存储桶*。
. 从表中选择存储桶名称。
+
此时将显示存储区详细信息页面。

. 在*存储桶选项*选项卡中，选择*上次访问时间更新*折叠面板。
. 启用或禁用上次访问时间更新。
. 选择 *Save changes*。
