= 如何使用 NetApp Console 管理 StorageGRID
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
转到 https://docs.netapp.com/us-en/storage-management-storagegrid/index.html["使用 NetApp Console 管理 StorageGRID"^]以了解如何使用 Grid Manager 从 NetApp Console 管理 StorageGRID 系统，并使用 NetApp Console 的数据服务进行备份、数据分层等。

*BlueXP 现已更名为 NetApp Console*

NetApp Console 基于经过增强和重构的 BlueXP 基础构建，提供对本地和云环境中 NetApp 存储和 NetApp Data Services 的企业级集中管理，提供实时洞察、更快的工作流程和简化的管理，高度安全且合规。

有关更改的详细信息，请参见 link:https://docs.netapp.com/us-en/console-relnotes/index.html["NetApp Console 发行说明"]。
