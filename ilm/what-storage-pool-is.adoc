= 了解 StorageGRID 中的存储池
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
存储池是存储节点的逻辑分组。

安装 StorageGRID 时，会自动为每个站点创建一个存储池。您可以根据存储需求配置其他存储池。


NOTE: 存储节点可以在安装过程中配置为包含对象数据和元数据（"组合"存储节点）、仅包含对象元数据或仅包含对象数据。仅元数据存储节点不能在存储池中使用。有关详细信息，请参阅 link:../primer/what-storage-node-is.html#types-of-storage-nodes["存储节点类型"]。

存储池有两个属性：

* *存储等级*：对于存储节点，后备存储的相对性能。
* *站点*：将存储对象的数据中心。


存储池在 ILM 规则中用于确定对象数据的存储位置和使用的存储类型。为复制配置 ILM 规则时，需要选择一个或多个存储池。
