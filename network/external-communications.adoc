= StorageGRID 的外部通信
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
客户端需要与网格节点进行通信，以获取和检索内容。使用的端口取决于所选的对象存储协议。这些端口需要可供客户端访问。



[[restricted-access-to-ports]]
== 限制访问端口

如果企业网络策略限制对任何端口的访问，则可以执行以下操作之一：

* 使用 link:../admin/configuring-load-balancer-endpoints.html["负载平衡器端点"] 允许访问用户定义的端口。
* 部署节点时重新映射端口。但是，不应重新映射负载平衡器端点。请参阅有关 StorageGRID 节点端口重新映射的信息：



NOTE: 对端口重新映射的支持已弃用，将在未来版本中删除。要删除重新映射的端口，请参阅 link:../maintain/removing-port-remaps.html["删除 StorageGRID 设备上的端口重映射"] 或 link:../maintain/removing-port-remaps-on-bare-metal-hosts.html["删除裸机主机上的端口重映射"]。

* link:../swnodes/creating-node-configuration-files.html["StorageGRID on Red Hat Enterprise Linux 的端口重映射密钥"]
* link:../swnodes/deploying-storagegrid-node-as-virtual-machine.html#vmware-remap-ports["在 VMware 上重新映射 StorageGRID 的端口"]
* https://docs.netapp.com/us-en/storagegrid-appliances/installconfig/optional-remapping-network-ports-for-appliance.html["可选：重新映射设备的网络端口"^]
