= 导航到 StorageGRID 网格管理器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Grid Manager 定义配置 StorageGRID 系统所需的所有信息。

.开始之前
必须部署主管理节点并完成初始启动序列。

.步骤
. 打开 Web 浏览器并导航到：
+
`https://_primary_admin_node_ip_`

+
或者，您可以在端口 8443 上访问 Grid Manager：

+
`https://_primary_admin_node_ip_:8443`

+
您可以根据网络配置使用网格网络或管理网络上的主管理节点 IP 的 IP 地址。您可能需要使用浏览器中的"安全"/"高级"选项来导航到不受信任的证书。

. 根据需要管理临时安装程序密码：
+
** 如果已使用其中一种方法设置密码，请输入密码以继续。
+
*** 用户先前在访问安装程序时设置了密码
*** 对于 Linux，密码是从以下位置的节点配置文件自动导入的： `/etc/storagegrid/nodes/_<node_name>_.conf`
*** 对于 VMware，SSH/控制台密码已从 OVF 属性自动导入


** 如果尚未设置密码，则可选择设置密码以保护 StorageGRID 安装程序。


. 选择 *Install a StorageGRID system*。
+
此时将显示用于配置 StorageGRID 网格的页面。

+
