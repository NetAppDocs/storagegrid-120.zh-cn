= 指定 StorageGRID 许可证信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必须指定 StorageGRID 系统的名称并上传由 NetApp 提供的许可证文件。

.步骤
. 在"许可证"页面上，在 *Grid Name* 字段中为您的 StorageGRID 系统输入一个有意义的名称。
+
安装后，名称将显示在节点菜单的顶端。

. 选择*浏览*，找到 NetApp 许可证文件(`NLF-_unique-id_.txt`），然后选择*打开*。
+
已验证许可证文件，并显示序列号。

+

NOTE: StorageGRID 安装存档包含一个免费许可证，该许可证不为产品提供任何支持授权。您可以在安装后更新为提供支持的许可证。

+
image:2_gmi_installer_license_page.png["StorageGRID 安装程序许可证页面"]

. 选择 *Next*。
