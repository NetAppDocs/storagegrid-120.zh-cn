= 在 StorageGRID 中添加站点
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
安装 StorageGRID 时，您必须至少创建一个站点。您可以创建其他站点，以提高 StorageGRID 系统的可靠性和存储容量。

.步骤
. 在"站点"页面上，输入*站点名称*。
. 要添加其他站点，请单击最后一个站点条目旁边的加号，然后在新的*站点名称*文本框中输入名称。
+
根据网格拓扑需要添加更多站点。最多可以添加 16 个站点。

+
