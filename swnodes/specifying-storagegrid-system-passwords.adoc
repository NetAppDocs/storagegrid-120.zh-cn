= 指定 StorageGRID 系统密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在安装 StorageGRID 系统时，需要输入用于保护系统和执行维护任务的密码。

.关于此任务
使用"安装密码"页面指定配置密码和网格管理 root 用户密码。

* 配置密码短语用作加密密钥，不由 StorageGRID 系统存储。
* 要执行安装、扩展和维护过程（包括下载恢复包），必须具有配置密码。因此，将配置密码存储在安全位置非常重要。
* 如果您拥有当前配置密码，则可以从 Grid Manager 更改配置密码。
* 可以使用 Grid Manager 更改网格管理 root 用户密码。
* 随机生成的命令行控制台和 SSH 密码存储在恢复包中的 `Passwords.txt`文件中。


.步骤
. 在*设置密码短语*中，输入更改 StorageGRID 系统的网格拓扑所需的设置密码短语。
+
将配置密码存储在安全的地方。

+

NOTE: 如果在安装完成后，您希望稍后更改设置密码，则可以使用 Grid Manager。选择 *Configuration* > *Access control* > *Grid passwords*。

. 在*确认设置密码短语*中，重新输入设置密码短语进行确认。
. 在 *Grid Management Root User Password* 中，输入以"root"用户身份访问 Grid Manager 的密码。
+

CAUTION: 将配置密码短语存储在安全位置。这是安装、扩展和维护程序所必需的。

. 在 *Confirm Root User Password* 中，重新输入 Grid Manager 密码进行确认。
+
image:10_gmi_installer_passwords_page.gif["本图四周的文字提供了相关说明。"]

. 如果要安装用于概念验证或演示目的的网格，可以选择取消选中*创建随机命令行密码*复选框。
+
对于生产部署，出于安全原因，应始终使用随机密码。如果要使用默认密码通过"root"或"admin"帐户从命令行访问网格节点，请仅对演示网格清除*创建随机命令行密码*。

+

NOTE: 单击"摘要"页面上的*安装*后，系统会提示您下载"恢复包"文件(`sgws-recovery-package-id-revision.zip`。您必须link:../maintain/downloading-recovery-package.html["下载此文件"]才能完成安装。访问系统所需的密码存储在 `Passwords.txt`文件中，该文件包含在恢复包文件中。

. 单击*下一步*。
