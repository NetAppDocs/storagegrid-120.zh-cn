= 升级 StorageGRID 软件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用以下说明将 StorageGRID 系统升级到新版本。

执行升级时，StorageGRID 系统中的所有节点都会升级。


CAUTION: 如果迫切需要扩展存储空间以增加容量（如果存储空间几乎已满），请勿开始升级。及时完成升级程序。如果需要恢复，请联系技术支持。
