= 升级前请检查您的 StorageGRID 系统的状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在升级 StorageGRID 系统之前，请验证系统是否已准备好进行升级。请确保系统正常运行，并且所有网格节点均可正常运行。

.步骤
. 使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到网格管理器。
. 检查并解决任何活动警报。
. 请参阅link:../network/internal-grid-node-communications.html["内部网格节点通信"]和link:../network/external-communications.html["外部通信"]，以确保在升级之前打开 StorageGRID 12.0 所需的所有端口。
+

NOTE: 升级到 StorageGRID 12.0 时不需要额外的端口。
