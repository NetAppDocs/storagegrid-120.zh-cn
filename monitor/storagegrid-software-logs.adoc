= StorageGRID 软件日志
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 StorageGRID 日志对问题进行故障排除。


NOTE: 如果要将日志发送到外部 syslog 服务器或更改审核信息的目标（如 `bycast.log`和 `nms.log`），请参阅link:../monitor/configure-log-management.html["配置日志管理"]。



[[general-storagegrid-logs]]
== 常规 StorageGRID 日志

[cols="3a,3a,2a"]
|===
| 文件名 | 说明 | 发现于 


| /var/local/log/bycast.log  a| 
主要 StorageGRID 故障排除文件。
 a| 
所有节点



| /var/local/log/bycast-err.log  a| 
包含 `bycast.log`的子集（严重性为 ERROR 和 CRITICAL 的消息）。CRITICAL 消息也会显示在系统中。
 a| 
所有节点



| /var/local/core/  a| 
包含在程序异常终止时创建的任何核心转储文件。可能的原因包括断言失败、违规或线程超时。

*Note*: 该文件 ``/var/local/core/kexec_cmd`通常存在于设备节点上，并不表示错误。
 a| 
所有节点

|===

[[nms-logs]]
== NMS 日志

[cols="3a,3a,2a"]
|===
| 文件名 | 说明 | 发现于 


| /var/local/log/nms.log  a| 
* 捕获来自 Grid Manager 和 Tenant Manager 的通知。
* 捕获与 NMS 服务操作相关的事件。例如，电子邮件通知和配置更改。
* 包含在系统中进行的配置更改导致的 XML 捆绑包更新。
* 包含与每天一次的属性降采样相关的错误消息。
* 包含Java Web服务器错误消息，例如，页面生成错误和HTTP状态500错误。
* 包含与 AutoSupport 相关的日志。

 a| 
管理节点



| /var/local/log/nms.errlog  a| 
包含与MySQL数据库升级相关的错误消息。

包含相应服务的标准错误 (stderr) 流。每个服务有一个日志文件。除非服务出现问题，否则这些文件通常为空。
 a| 
管理节点



| /var/local/log/nms.requestlog  a| 
包含有关从 Management API 到内部 StorageGRID 服务的传出连接的信息。
 a| 
管理节点

|===
