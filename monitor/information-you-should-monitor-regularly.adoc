= 在 StorageGRID 中监控什么以及何时监控
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
即使 StorageGRID 系统可以在发生错误或网格部分节点不可用时继续运行，您也应该在潜在问题影响网格效率或可用性之前对其进行监控和处理。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到网格管理器。
* 您有 link:../admin/admin-group-permissions.html["特定访问权限"]。
