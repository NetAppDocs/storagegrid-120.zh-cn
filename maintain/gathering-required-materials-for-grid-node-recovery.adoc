= 收集 StorageGRID 网格节点恢复所需的材料
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在执行维护程序之前，您必须确保拥有恢复故障网格节点所需的材料。

[cols="1a,2a"]
|===
| 个项目 | 说明 


 a| 
StorageGRID 安装归档
 a| 
如果需要恢复网格节点，则需要为您的平台<<download-and-extract-install-files-recover,下载 StorageGRID 安装文件>>。

*注意：* 如果要在存储节点上恢复发生故障的存储卷，则无需下载文件。



 a| 
维修笔记本电脑
 a| 
维修笔记本电脑必须具有以下条件：

* 网络端口
* SSH 客户端（例如 PuTTY）
* link:../admin/web-browser-requirements.html["支持的 Web 浏览器"]




 a| 
恢复包 `.zip`文件
 a| 
获取最新恢复包 `.zip`文件的副本：
`sgws-recovery-package-_id-revision_.zip`

 `.zip` 文件的内容会在每次修改系统时更新。进行此类更改后，系统会指示您将最新版本的恢复包存储在安全位置。使用最新副本从网格故障中恢复。

登录到任何管理节点时，请使用 Grid Manager 下载恢复包。选择 *维护* > *系统* > *恢复包*。

如果您无法访问 Grid Manager，则可以在包含 ADC 服务的某些存储节点上找到恢复包的加密副本。在每个存储节点上，检查此位置的恢复包： `/var/local/install/sgws-recovery-package-_grid-id_-_revision_.zip.gpg`使用修订版本号最高的恢复包。



 a| 
`Passwords.txt` 文件
 a| 
包含访问命令行上的网格节点所需的密码。包含在恢复包中。



 a| 
配置密码短语
 a| 
密码在首次安装 StorageGRID 系统时创建并记录。配置密码短语不在 `Passwords.txt`文件中。



 a| 
适用于您平台的当前文档
 a| 
转到平台供应商的网站以获取文档。

有关平台的当前支持版本，请参见 https://imt.netapp.com/matrix/#welcome["NetApp 互操作性表工具"^]。

|===


[[download-and-extract-storagegrid-installation-files]]
== 下载并提取 StorageGRID 安装文件

.[[download-and-extract-install-files-recover]]
下载软件并提取文件，除非您是 link:recovering-from-storage-node-failures.html["在存储节点上恢复发生故障的存储卷"]。

您必须使用当前在网格上运行的 StorageGRID 版本。

.步骤
. 确定当前安装的软件版本。在 Grid Manager 顶端，选择帮助图标，然后选择*关于*。
. 转到  https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp StorageGRID 的下载页面"^]。
. 选择当前在网格上运行的 StorageGRID 版本。
+
StorageGRID 软件版本的格式为： `11.x.y`。

. 使用您 NetApp 帐户的用户名和密码登录。
. 阅读最终用户许可协议，选中复选框，然后选择 *Accept & Continue*。
. 在下载页面的 *Install StorageGRID* 列中，选择适用于您平台的 `.tgz`或 `.zip`文件。
+
安装存档文件中显示的版本必须与当前安装的软件版本相匹配。

+
如果运行的是 Windows，请使用  `.zip` 文件。

+
[cols="1a,2a"]
|===
| 平台 | 安装归档 


 a| 
RHEL
| `StorageGRID-Webscale-_version_-RPM-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.tgz` 


 a| 
Ubuntu 或 Debian 或设备
| `StorageGRID-Webscale-_version_-DEB-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.tgz` 


 a| 
VMware
| `StorageGRID-Webscale-_version_-VMware-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-VMware-_uniqueID_.tgz` 
|===
. 下载并提取存档文件。
. 根据您的平台和需要恢复的网格节点，跳转到平台的相应部分以选择所需的文件。
+
步骤中列出的每个平台的路径均相对于归档文件安装的顶级目录。

. 如果要恢复link:../swnodes/index.html["基于软件的节点"]，请选择相应的文件：
