= 停用多个 StorageGRID 存储节点
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果需要删除多个存储节点，可以按顺序或并行停用它们。


CAUTION: 在包含基于软件的仅元数据节点的网格中停用存储节点时，请谨慎操作。如果取消配置为同时存储对象和元数据的所有节点，则存储对象的功能将从网格中删除。有关仅元数据存储节点的详细信息，请参见 link:../primer/what-storage-node-is.html#types-of-storage-nodes["存储节点类型"]。

* 如果按顺序停用存储节点，则必须等待第一个存储节点完成停用，然后才能开始停用下一个存储节点。
* 如果并行停用存储节点，则存储节点将同时处理要停用的所有存储节点的停用任务。这可能会导致文件的所有永久副本被标记为"只读"，从而在启用此功能的网格中暂时禁用删除。
