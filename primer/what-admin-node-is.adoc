= 什么是 StorageGRID 管理节点？
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理节点提供系统配置、监控和日志记录等管理服务。管理节点也可用于负载平衡 S3 客户端流量。每个网格必须有一个主管理节点，并且可以具有任意数量的非主管理节点以实现冗余。



[[differences-between-primary-and-non-primary-admin-nodes]]

[[preferred-senderpreferred-sender-admin-node]]
== [[preferred-sender]]首选发件人管理节点

如果您的 StorageGRID 部署包括多个管理节点，则主管理节点是警报通知、AutoSupport 包和 SNMP 陷阱和通知的首选发件人。

在正常系统操作下，只有首选发件人才会发送通知。但是，所有其他管理节点都会监视首选发件人。如果检测到问题，其他管理节点将充当备用发件人。

在以下情况下，系统可能会发送多条通知：

* 如果管理节点彼此"孤立"，则首选发件人和备用发件人都将尝试发送通知，并且可能会收到多个通知副本。
* 如果备用发件人检测到首选发件人的问题并开始发送通知，则首选发件人可能会重新获得发送通知的能力。如果发生这种情况，可能会发送重复的通知。当备用发件人不再检测到首选发件人的错误时，它将停止发送通知。
+

NOTE: 当您测试 AutoSupport 包时，所有管理节点都会发送测试。当您测试警报通知时，您必须登录到每个管理节点以验证连接。





[[primary-services-for-admin-nodes]]
== 管理节点的主要服务

下表显示了管理节点的主要服务；但是，此表未列出所有节点服务。

[cols="1a,2a"]
|===
| 服务 | 关键功能 


 a| 
[[ams]]审核管理系统(AMS)
 a| 
跟踪系统活动和事件。



 a| 
[[cmn]]配置管理节点(CMN)
 a| 
管理全系统配置。



 a| 
[[high-availability]]高可用性
 a| 
管理管理节点和网关节点组的高可用性虚拟 IP 地址。

*注：* 此服务也可在网关节点上找到。



 a| 
[[load-balancer]]负载平衡器
 a| 
提供从客户端到存储节点的 S3 流量的负载均衡。

*注：* 此服务也可在网关节点上找到。



 a| 
[[mgmt-api]]管理应用程序接口（mgmt-api）
 a| 
处理来自 Grid Management API 和 Tenant Management API 的请求。



 a| 
[[nms]]网络管理系统(NMS)
 a| 
为 Grid Manager 提供功能。



 a| 
[[prometheus]]Prometheus
 a| 
从所有节点上的服务收集和存储时间序列指标。



 a| 
[[ssm]] 服务器状态监视器 (SSM)
 a| 
监控操作系统和底层硬件。

|===
