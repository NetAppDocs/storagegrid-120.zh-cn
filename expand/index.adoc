= 了解如何扩展 StorageGRID 系统
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解如何扩展 StorageGRID 系统以在不中断操作的情况下增加容量或功能。可以将存储卷添加到现有存储节点、将新网格节点添加到现有站点或添加新站点。

在扩展网格节点之前，您必须确认没有数据修复作业处于活动状态。如果任何修复失败，您必须重新启动这些修复，并在执行停用或扩展操作之前等待其完成。请参阅 link:../maintain/checking-data-repair-jobs.html["检查数据修复作业"]。

通过 StorageGRID 扩展，您可以添加：

* 存储卷到存储节点
* 向现有站点添加新网格节点
* 全新站点


执行扩展的原因决定了必须添加的每种类型的新节点数以及这些新节点的位置。例如，如果您正在执行扩展以增加存储容量、添加元数据容量或添加冗余或新功能，则存在不同的节点要求。

按照您正在执行的扩展类型的步骤进行操作：
