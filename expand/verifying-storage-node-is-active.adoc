= 验证 StorageGRID 扩展后存储节点是否处于活动状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在添加新存储节点的扩容操作完成后，StorageGRID 系统应自动开始使用新的存储节点。您必须使用 StorageGRID 系统来验证新的存储节点是否处于活动状态。

.步骤
. 使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到网格管理器。
. 选择*节点* > *_扩展存储节点_* > *存储*。
