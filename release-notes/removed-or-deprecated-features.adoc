= StorageGRID 中已删除或弃用的功能和特性
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解 StorageGRID 12.0 中已删除或弃用的特性和功能。在升级之前，请检查任何已删除或已弃用的功能是否会影响客户端应用程序或网格配置。



[[definitions]]
== 定义

已弃用:: 该功能*不应*在新的生产环境中使用。现有生产环境可以继续使用该功能。
生命周期结束:: 支持该功能的最新发货版本。在某些情况下，此阶段可能会删除该功能的文档。
已删除:: 第一个*不*支持此功能的版本。




[[storagegrid-end-of-feature-support]]
== StorageGRID 功能支持终止

已弃用的功能将在 N+2 主要版本中删除。例如，如果某个功能在版本 N 中被弃用（例如 6.3），则该功能将存在的最后一个版本为 N+1（例如 6.4）。版本 N+2（例如 6.5）是产品中不再包含该功能的第一个版本。

有关其他信息，请参见 https://mysupport.netapp.com/site/info/version-support["软件版本支持页面"^]。


NOTE: 在某些情况下，NetApp 可能会提前终止对特定功能的支持。
