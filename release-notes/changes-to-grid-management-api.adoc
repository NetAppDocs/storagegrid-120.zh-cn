= StorageGRID 中网格管理 API 的更改
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.0 使用网格管理 API 第 4 版。版本 4 弃用版本 3；但是，仍支持版本 1、2 和 3。


NOTE: 您可以继续在 StorageGRID 12.0 中使用已弃用的管理 API 版本；但是，对这些 API 版本的支持将在未来的 StorageGRID 版本中移除。升级到 StorageGRID 12.0 后，您可以使用 `PUT /grid/config/management` API 停用已弃用的 API。

要了解更多信息，请转到 link:../admin/using-grid-management-api.html["使用 Grid Management API"]。



[[new-endpoints-for-branch-buckets]]
== 分支存储桶的新端点

已添加以下端点，以允许您 link:../tenant/what-is-branch-bucket.html["管理分支存储桶"]：

`GET /org/containers/{branchBucketName}/branch`

`PUT /org/containers/{branchBucketName}/branch`



[[new-private-endpoints-for-move-adc]]
== Move ADC 的新专用端点

已添加以下专用端点，以允许您在同一站点上link:../maintain/move-adc-service.html["移动 ADC 服务"]从一个存储节点到另一个存储节点：

`/private/move-adc`

`/private/move-adc/start`

`/private/move-adc/retry`



[[new-private-endpoints-for-convert-to-data-only-node]]
== 用于转换为仅数据节点的新专用终结点

已添加以下专用端点，以允许您将不包含 ADC 服务的 link:../maintain/convert-to-data-only-node.html["转换一个或多个组合存储节点"] 端点添加到仅数据节点中。

`/private/convert-to-data-only-node`

`/private/convert-to-data-only-node/start`

`/private/convert-to-data-only-node/retry`
