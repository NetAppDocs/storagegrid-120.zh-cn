= StorageGRID 中正常节点停止的 SYSD 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
正常停止服务时，将生成此消息以指示请求关闭。通常，此消息仅在后续重新启动后发送，因为在关闭之前不会清除审核消息队列。如果服务尚未重新启动，请查找在关闭序列开始时发送的 SYST 消息。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
RSLT
 a| 
正常关机
 a| 
关闭的性质：

SUCS：系统已正常关闭。

|===
该消息不指示主机服务器是否正在停止，仅指示报告服务。SYSD 的 RSLT 不能指示"脏"关闭，因为消息仅由"干净"关闭生成。
