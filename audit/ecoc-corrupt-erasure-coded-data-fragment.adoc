= StorageGRID 中损坏的纠删编码数据的 ECOC 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此审核消息指示系统已检测到损坏的擦除编码数据片段。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
VCCO
 a| 
VCS ID
 a| 
包含损坏区块的 VCS 的名称。



 a| 
VLID
 a| 
Volume ID
 a| 
包含损坏的纠删编码片段的 RangeDB 卷。



 a| 
CCID
 a| 
区块ID
 a| 
损坏的擦除编码片段的标识符。



 a| 
RSLT
 a| 
结果
 a| 
此字段的值为"NONE"。RSLT 是必填消息字段，但与此特定消息无关。使用"NONE"而不是"SUCS"，因此不会过滤此消息。

|===
