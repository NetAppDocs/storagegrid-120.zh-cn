= StorageGRID 中空存储桶对象删除的 EBDL 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ILM 扫描程序删除了一个存储桶中的对象，该存储桶正在删除所有对象（执行清空存储桶操作）。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
CSIZ
 a| 
对象大小
 a| 
对象的大小（以字节为单位）。



 a| 
路径
 a| 
S3 存储桶/键
 a| 
S3 存储桶名称和 S3 密钥名称。



 a| 
SEGC
 a| 
容器UUID
 a| 
分段对象的容器的 UUID。此值仅在对象已分段时可用。



 a| 
UUID
 a| 
通用唯一标识符
 a| 
StorageGRID 系统中对象的标识符。



 a| 
RSLT
 a| 
删除操作的结果
 a| 
事件、流程或事务的结果。如果与消息无关，则使用 NONE 而不是 SUCS，以免意外过滤消息。

|===
