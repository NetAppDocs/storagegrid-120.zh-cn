= StorageGRID 中安全审核禁用的 SADD 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此消息指示原始服务（节点 ID）已关闭审核消息日志记录。StorageGRID 不再收集或传递审核消息。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
AETM
 a| 
启用方法
 a| 
用于禁用审核的方法。



 a| 
AEUN
 a| 
用户名
 a| 
执行命令以禁用审核日志记录的用户名。



 a| 
RSLT
 a| 
结果
 a| 
此字段的值为 NONE。RSLT 是必填消息字段，但与此消息无关。使用 NONE 而不是 SUCS，以确保此消息不会被过滤。

|===
该消息暗示日志记录以前已启用，但现在已被禁用。这通常仅在批量摄取时使用，以提高系统性能。在批量活动之后，将恢复审核（SADE），然后永久阻止禁用审核的功能。
