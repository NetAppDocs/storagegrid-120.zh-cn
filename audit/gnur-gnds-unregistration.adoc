= StorageGRID 中 GNDS 注销的 GNUR 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当服务从 StorageGRID 系统注销其自身相关信息时，CMN 服务将生成此审核消息。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
RSLT
 a| 
结果
 a| 
更新请求的结果：

* SUCS：成功
* SUNV：服务不可用
* GERR：其他故障




 a| 
GNID
 a| 
节点 ID
 a| 
启动更新请求的服务的节点 ID。

|===
