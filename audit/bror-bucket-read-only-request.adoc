= StorageGRID 中存储桶只读请求的 BROR 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当存储区进入或退出只读模式时，LDR 服务会生成此审核消息。例如，在删除所有对象时，存储区进入只读模式。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
BKHD
 a| 
存储桶 UUID
 a| 
存储桶 ID。



 a| 
BROV
 a| 
存储区只读请求值
 a| 
存储桶是否处于只读状态或正在退出只读状态（1 = 只读，0 = 非只读）。



 a| 
BROS
 a| 
存储桶只读原因
 a| 
存储区被设为只读或离开只读状态的原因。例如，emptyBucket。



 a| 
S3AI
 a| 
S3租户帐户ID
 a| 
发送请求的租户帐户的 ID。空值表示匿名访问。



 a| 
S3BK
 a| 
S3 存储分段
 a| 
S3 存储桶名称。

|===
