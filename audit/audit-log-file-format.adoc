= 了解 StorageGRID 中审计日志文件的格式
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
审核日志文件位于每个管理节点上，包含各个审核消息的集合。

每条审核消息都包含以下内容：

* 触发审核消息 (ATIM) 的事件的协调世界时 (UTC)，采用 ISO 8601 格式，后跟空格：
+
`_YYYY-MM-DDTHH:MM:SS.UUUUUU_`，其中 `_UUUUUU_`为微秒。

* 审核消息本身，括在方括号内并以 `AUDT`开头。

在默认格式中，审核日志文件中的审核消息不容易阅读或解释。您可以使用 link:using-audit-explain-tool.html["audit-explain 工具"] 获取审核日志中审核消息的简化摘要。您可以使用 link:using-audit-sum-tool.html["audit-sum 工具"] 汇总记录了多少次写入、读取和删除操作以及这些操作花费了多长时间。
