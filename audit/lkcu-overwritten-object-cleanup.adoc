= StorageGRID 中覆盖对象清理的 LKCU 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此消息是在 StorageGRID 删除先前需要清理以释放存储空间的已覆盖对象时生成的。当 S3 客户端将对象写入已包含对象的路径时，对象将被覆盖。删除过程会自动在后台执行。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
CSIZ
 a| 
内容大小
 a| 
对象的大小（以字节为单位）。



 a| 
LTYP
 a| 
清理类型
 a| 
_仅供内部使用。_



 a| 
LUID
 a| 
已删除对象 UUID
 a| 
已删除的对象的标识符。



 a| 
路径
 a| 
S3 存储桶/键
 a| 
S3 存储桶名称和 S3 密钥名称。



 a| 
SEGC
 a| 
容器UUID
 a| 
分段对象的容器的 UUID。此值仅在对象已分段时可用。



 a| 
UUID
 a| 
通用唯一标识符
 a| 
仍然存在的对象的标识符。此值仅在对象未被删除时可用。

|===
