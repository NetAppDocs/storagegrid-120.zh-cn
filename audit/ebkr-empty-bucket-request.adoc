= StorageGRID 中空存储桶请求的 EBKR 审核消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此消息表示用户发送了打开或关闭空存储桶的请求（即删除存储桶对象或停止删除对象）。

[cols="1a,1a,4a"]
|===
| 代码 | 字段 | 问题描述 


 a| 
BUID
 a| 
存储桶 UUID
 a| 
存储桶 ID。



 a| 
EBJS
 a| 
空的 Bucket JSON 配置
 a| 
包含表示当前 Empty Bucket 配置的 JSON。



 a| 
S3AI
 a| 
S3租户帐户ID
 a| 
发送请求的用户的租户帐户 ID。空值表示匿名访问。



 a| 
S3BK
 a| 
S3 存储桶
 a| 
S3 存储桶名称。

|===
