= 在 StorageGRID 中管理用户
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看本地用户和联合用户。您还可以创建本地用户并将其分配给本地管理组，以确定这些用户可以访问哪些 Grid Manager 功能。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到网格管理器。
* 您有 link:admin-group-permissions.html["特定访问权限"]。




[[create-a-local-user]]
== 创建本地用户

您可以创建一个或多个本地用户，并将每个用户分配到一个或多个本地组。组的权限控制用户可以访问的 Grid Manager 和 Grid Management API 功能。

您只能创建本地用户。使用外部身份源管理联合用户和组。

网格管理器包括一个名为"root"的预定义本地用户。您无法删除 root 用户。


NOTE: 如果启用了单一登录 (SSO)，则本地用户无法登录到 StorageGRID。



[[access-the-wizard]]
=== 访问此向导

.步骤
. 选择*配置* > *访问控制* > *管理员用户*。
. 选择*创建用户*。




[[enter-user-credentials]]
=== 输入用户凭据

.步骤
. 输入用户的全名、唯一的用户名和密码。
. （可选）如果此用户无权访问 Grid Manager 或 Grid Management API，请选择 *Yes*。
. 选择 *Continue*。




[[assign-to-groups]]
=== 分配到组

.步骤
. 可选操作：将用户分配给一个或多个组，以确定用户的权限。
+
如果您尚未创建组，则可以在不选择组的情况下保存该用户。您可以在“组”页面上将此用户添加到组中。

+
如果用户属于多个组，则权限是累积的。请参见 link:managing-admin-groups.html["管理管理员组"] 了解详细信息。

. 选择*创建用户*并选择*完成*。




[[view-and-edit-local-users]]
== 查看和编辑本地用户

您可以查看现有本地用户和联合用户的详细信息。您可以修改本地用户，以更改该用户的全名、密码或组群成员身份。您还可以临时阻止用户访问 Grid Manager 和 Grid Management API。

您只能编辑本地用户。请使用外部身份源来管理联合用户。

* 若要查看所有本地和联合用户的基本信息，请查看"用户"页面上的表。
* 要查看特定用户的所有详细信息、编辑本地用户或更改本地用户的密码，请使用*操作*菜单或详细信息页面。
+
下次用户注销并重新登录到 Grid Manager 时，将应用所做的任何编辑。

+

NOTE: 本地用户可以使用网格管理器横幅中的*更改密码*选项更改自己的密码。

[[import-federated-users]]
== 导入联合用户

您可以将一个或多个联合用户（最多 100 个用户）直接导入到"用户"页面。

.步骤
. 选择*配置* > *访问控制* > *管理员用户*。
. 选择*导入联合用户*。
. 输入一个或多个联合用户的 UUID 或用户名。
+
对于多个条目，请在新行中添加每个 UUID 或用户名。

. 选择*导入*。
+
如果一个或多个用户的"用户"字段导入失败，请执行以下步骤：

+
.. 展开*未导入的用户*并选择*复制用户*。
.. 通过选择*上一步*并将复制的用户粘贴到*导入联合用户*对话框中，重试导入。


+
关闭*导入联合用户*对话框后，成功导入的用户的联合用户信息将显示在用户页面上。





[[duplicate-a-user]]
== 复制用户

您可以复制现有用户以创建具有相同权限的新用户。

.步骤
. 选中该用户的复选框。
. 选择*操作* > *复制用户*。
. 完成复制用户向导。




[[delete-a-user]]
== 删除用户

您可以删除本地用户以从系统中永久删除该用户。


NOTE: 您无法删除 root 用户。

.步骤
. 从"用户"页中，选中要删除的每个用户的复选框。
. 选择*操作* > *删除用户*。
. 选择*删除用户*。
