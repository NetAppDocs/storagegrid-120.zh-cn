= 删除 StorageGRID 流量分类策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您不再需要流量分类策略，可以将其删除。请确保删除了正确的策略，因为策略一旦删除便无法恢复。

.开始之前
* 您已使用 link:../admin/web-browser-requirements.html["支持的 Web 浏览器"] 登录到网格管理器。
* 您有 link:admin-group-permissions.html["root 访问权限"]。


.步骤
. 选择*配置* > *网络* > *流量分类*。
