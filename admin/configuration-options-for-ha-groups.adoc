= StorageGRID 高可用性组的配置选项
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
以下图表提供了配置高可用性 (HA) 组的不同方法的示例。每个选项都有优点和缺点。

在图中，蓝色表示 HA 组中的主接口，黄色表示 HA 组中的备份接口。

image:high_availability_examples.png["HA 示例"]

下表总结了图中所示的每个 HA 配置的优点。

[cols="1a,2a,2a"]
|===
| 配置 | 优势 | 劣势 


 a| 
活动-备份 HA
 a| 
* 由 StorageGRID 管理，无外部依赖关系。
* 快速故障转移。

 a| 
* HA 组中只有一个节点处于活动状态。每个 HA 组至少有一个节点将处于空闲状态。




 a| 
DNS 轮询
 a| 
* 提高聚合吞吐量。
* 无空闲主机。

 a| 
* 故障转移速度较慢，这可能取决于客户端行为。
* 需要在 StorageGRID 外部配置硬件。
* 需要客户实施的运行状况检查。




 a| 
主动-主动 HA
 a| 
* 流量分布在多个 HA 组中。
* 高聚合吞吐量，随 HA 组的数量而扩展。
* 快速故障转移。

 a| 
* 配置更复杂。
* 需要在 StorageGRID 外部配置硬件。
* 需要客户实施的运行状况检查。


|===
