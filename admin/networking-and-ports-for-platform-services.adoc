= StorageGRID 平台服务的网络和端口
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您允许 S3 租户使用平台服务，则必须为网格配置网络，以确保平台服务消息可以传递到其目的地。

创建或更新租户帐户时，可以为 S3 租户帐户启用平台服务。如果启用了平台服务，租户可以创建端点，作为 CloudMirror 复制、事件通知或从其 S3 存储桶搜索集成消息的目标。这些平台服务消息从运行 ADC 服务的存储节点发送到目标端点。

例如，租户可以配置以下类型的目标端点：

* 本地托管的 Elasticsearch 集群
* 支持接收 Amazon Simple Notification Service 消息的本地应用程序
* 本地托管的 Kafka 集群
* 支持 HTTP POST 通知请求的外部或本地托管的 Webhook 端点。
+
此端点可以托管在各种 Web 服务器、框架或 Fluentd 等数据处理工具上。

* 同一个或另一个 StorageGRID 实例上本地托管的 S3 存储桶
* 外部端点，例如 Amazon Web Services 上的端点。


为了确保平台服务消息可以传递，您必须配置包含 ADC 存储节点的网络。必须确保可以使用以下端口将平台服务消息发送到目标端点。

默认情况下，平台服务消息通过以下端口发送：

* *80*：对于以 http 开头的端点 URI（大多数端点）
* *443*：对于以 HTTPS 开头的端点 URI（大多数端点）
* *9092*：用于以 http 或 https 开头的端点 URI（仅限 Kafka 端点）


租户可以在创建或编辑端点时指定其他端口。


NOTE: 如果将 StorageGRID 部署用作 CloudMirror 复制的目标，则可能会在 80 或 443 以外的端口上接收复制消息。请确保在端点中指定了目标 StorageGRID 部署用于 S3 的端口。

如果使用不透明的代理服务器，则还必须link:configuring-storage-proxy-settings.html["配置存储代理设置"]以允许将消息发送到外部端点，例如 Internet 上的端点。
